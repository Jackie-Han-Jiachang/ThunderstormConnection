# 《雷雨》人物关系网

一个供中文课堂使用的离线互动应用。用户可以创建《雷雨》事件卡片，把事件从“预备事件”放到“已发生事件”，并观察角色好感度如何改变人物关系网。

## 网页功能简介

网页通过“事件”演绎《雷雨》人物关系的变化，适合课堂讲解、分组讨论和情节复盘。页面分为三个区域：

- **角色关系网**：展示参与已发生事件的人物及其关系。连线旁的数字是两人累计的好感度；正数表示好感，负数表示疏离，数值的绝对值越大，连线越粗。好感度越高，人物在图中通常越靠近。角色节点可以用鼠标拖动，方便整理关系图。
- **已发生事件**：列出已经执行、正在影响关系网的事件。新执行的事件显示在上方。
- **预备事件**：保存尚未执行的事件卡片。在这里可以创建、编辑、删除或执行事件；预备事件不会影响关系网。

系统提供周繁漪、鲁贵、鲁侍萍、鲁四凤、鲁大海、周朴园、周萍和周冲八位角色。多次事件对同一对人物产生的好感度变化会累加，因此可以用一系列事件逐步演绎人物关系。

## 如何使用网页

1. 启动应用并在浏览器打开 [http://localhost:8080](http://localhost:8080)。
2. 点击预备事件区域中的“创建新事件”。
3. 填写事件名称和描述，选择发起人及一位或多位被影响人，再用滑块设置好感度变化（`-10` 至 `+10`）。
4. 点击“保存到预备事件”。保存后的卡片可以继续编辑或删除。
5. 点击卡片上的“执行事件”，将它移入已发生事件区。关系网会立即按该事件更新。
6. 观察人物之间的连线、累计分数和距离变化；可以拖动人物节点调整布局。
7. 如需修改演绎结果，点击已发生事件上的“撤回到预备事件”。撤回后，该事件的影响会从关系网中移除，并可再次编辑或执行。

例如，创建“花园相遇”，选择“周冲”为发起人、“鲁四凤”为被影响人，并设置好感度 `+6`。执行后，关系网会出现两个人物及一条标有 `+6` 的好感连线。如果随后执行一个使两人好感度 `-2` 的事件，连线上的累计分数会变为 `+4`。

> 关系网只根据“已发生事件”计算。首次使用时图中没有人物是正常现象，执行第一个事件后便会生成关系网。

## 环境要求

- Java 17 或更高版本
- Maven 3.9 或更高版本（仅构建时需要）

## 运行

### 双击运行

Mac用户双击share文件夹中`run_mac.command`

Windows 用户双击share文件夹中`run_win.bat`

程序启动期间不用关闭任何弹出的terminal窗口，等待默认浏览器打开即可。

### 在CLI中运行
```bash
./mvnw clean package
java -jar target/thunderstorm-1.0.0.jar
```

然后在浏览器打开 [http://localhost:8080](http://localhost:8080)。

Windows 构建时使用：

```powershell
mvnw.cmd clean package
java -jar target\thunderstorm-1.0.0.jar
```

应用完全离线运行。事件数据默认保存在：

- macOS/Linux：`~/.thunderstorm/events.json`
- Windows：`%USERPROFILE%\\.thunderstorm\\events.json`

如需使用其他数据文件：

```bash
java -jar target/thunderstorm-1.0.0.jar --thunderstorm.data-file=/absolute/path/events.json
```
